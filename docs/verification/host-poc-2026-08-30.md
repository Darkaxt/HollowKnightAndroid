## Serialized-file transformer

Task 5 was implemented with legal synthetic Unity 6000.0.61f1 serialized
files generated from the pinned AssetsTools.NET class database. The red test
first failed because `SerializedFileTransformer` did not exist. The completed
suite then proved:

- required Vulkan coverage fails before publishing an output;
- optional missing-Vulkan compatibility passes the original shader through;
- target platform 24 is rewritten to Android target 13;
- Vulkan selection retains only platform 18 and its compressed blob range;
- every chunk of a multi-chunk Vulkan platform is retained with contiguous
  rewritten offsets;
- output is written to `.part`, reopened and verified, and only then renamed;
- extensionless serialized files such as `level0` are recognized from their
  header rather than their filename;
- standalone files and UnityFS bundle entries call the same in-memory
  transformation core.

## Classic Unity player-tree converter

Task 6 adds content-based discovery, exact-manifest validation, conversion,
and inventory commands for classic Unity player trees. The legal synthetic
suite proves:

- extensionless serialized-file discovery and directory-scoped numeric sort;
- deterministic file and tree hashes with exact `.resS`/`.resource` owners;
- rejection of missing files, traversal, case/numeric aliases, Windows
  trailing-dot/space aliases, non-Linux serialized targets, and overlapping
  command paths;
- manifest actions `TRANSFORM`, `COPY`, `EXCLUDE`, and
  `REPLACE_AT_ASSEMBLY` before conversion can begin;
- every selected serialized output is Android target 13 with Vulkan platform
  18 retained, while source hashes remain unchanged;
- output-only BuildSettings graphics API and optional Unity-version
  normalization;
- hash-verified resume, tamper repair, `.part` report publication, and
  versioned failure reports, including malformed-manifest failures;
- media/plugin/shader census, byte-identical sidecar copies, and explicit
  exclusion/replacement reports for desktop plugins and built-ins.
