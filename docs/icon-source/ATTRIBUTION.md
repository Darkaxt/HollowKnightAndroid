# Icon source and adaptation record

The repository owner supplied the six source images below for inclusion in
HollowKnightAndroid on 2026-08-30. The corrected combined image is the final,
authoritative composition for the README and APK icon. Its elements are not
reconstructed or repositioned. The five component images are retained only so
the same visual language may be reused in the launcher UI later.

`adaptive-master.png` is only a deterministic resize of the corrected combined
image. Density-specific legacy and adaptive Android PNGs are deterministic
resizes of that unchanged composition. Round resources add only a circular
alpha mask. The separately supplied background, console, and masks are not
used to reconstruct the icon.

No generative image output is retained in this repository or used in the
README, Android resources, or APK.
