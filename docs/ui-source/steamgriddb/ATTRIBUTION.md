# User-selected SteamGridDB UI sources

These eight files are the exact originals selected by the project owner on
2026-08-31. They were downloaded from SteamGridDB's CDN and stored without
pixel, color, crop, animation, or format changes. No image-generation tool was
used.

They are source references for the two-game launcher UI. They are deliberately
outside every Android source set and are not packaged in the APK yet. Any
release-sized derivative must be reproducible, must preserve its source file,
and must be reviewed in the actual launcher layout before replacing it.
